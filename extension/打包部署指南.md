# 扩展打包和部署指南

## 📦 打包说明

### ✅ 好消息：扩展可以独立运行！

**Chrome扩展已经实现完全独立运行，可以直接打包 `extension` 目录使用！**

根据 `IMPLEMENTATION_SUMMARY.md` 的说明，扩展已经：
- ✅ 移除了后端服务器依赖

- ✅ 不需要Node.js环境

### 📦 直接打包 extension 目录

**可以只打包 `extension` 目录！** 扩展是完全独立的，包含所有必要的功能：

1. **图片搜索和提取**（Content Script）

## 🚀 在新电脑上部署的完整步骤

### 第一步：打包 extension 目录

**只需要打包 `extension` 目录！**

```bash
# 在当前电脑上，进入项目目录
cd /path/to/xiaohongshu

# 方式一：使用zip打包（推荐）
zip -r xiaohongshu-extension.zip extension/

# 方式二：使用tar打包
tar -czf xiaohongshu-extension.tar.gz extension/
```

### 第二步：传输到新电脑

将打包好的文件传输到新电脑，然后解压：
```bash
# 解压zip文件
unzip xiaohongshu-extension.zip

# 或解压tar文件
tar -xzf xiaohongshu-extension.tar.gz
```

### 第三步：安装Chrome扩展

1. **打开Chrome扩展管理页面**
   - 访问 `chrome://extensions/`
   - 或者：菜单 → 更多工具 → 扩展程序

2. **开启开发者模式**
   - 点击右上角的"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择项目中的 `extension` 目录
   - 扩展安装完成

4. **验证安装**
   - 浏览器工具栏应该显示扩展图标
   - 点击图标，应该能打开 `http://localhost:3000` 的Web界面

### 第四步：使用扩展

1. **登录小红书**
   - 在小红书网站（https://www.xiaohongshu.com）完成登录

2. **配置扩展**
   - 点击浏览器工具栏中的扩展图标
   - 打开Popup界面
   - 配置下载选项（图片数量、去水印等）
   - 配置AI功能（可选，需要API密钥）

3. **添加餐馆并开始下载**
   - 在Popup中添加餐馆名称和地点
   - 点击"开始下载"按钮
   - 在Popup中查看下载进度和日志

## 🔧 常见问题

### Q1: 可以只打包 extension 目录吗？

**A**: **可以！** 扩展已经完全独立运行，只需要打包 `extension` 目录即可。不需要Node.js、不需要Web服务器、不需要其他项目文件。

### Q2: 在新电脑上需要安装什么？

**A**: **只需要Chrome浏览器！** 扩展完全在浏览器中运行，不需要安装Node.js或其他依赖。

### Q3: 扩展安装后无法使用怎么办？

**A**: 请检查：
1. 扩展是否正确加载（chrome://extensions/ 中显示已启用）
2. 是否在小红书网站完成登录
3. 浏览器控制台是否有错误信息（F12打开开发者工具）
4. 网络连接是否正常

### Q4: 如何配置AI功能？

**A**: 
1. 点击扩展图标，打开Popup
2. 点击"高级设置"展开AI配置
3. 输入GLM API密钥
4. 启用"启用AI智能生成评语"
5. 配置其他AI选项（可选）

### Q5: 扩展支持哪些浏览器？

**A**: 
- Chrome 88+（Manifest V3）
- Edge 88+（基于Chromium）
- 其他基于Chromium的浏览器
