## 插件简介

**小红书餐馆图片下载工具** 是一个Chrome浏览器扩展插件，可以帮助您：

- 🔍 根据餐馆名称和地点智能搜索小红书内容
- 📥 批量下载餐馆相关图片
- 🚫 智能去除图片水印
- 🤖 AI智能分析图片内容，生成餐馆描述和评语
- 💾 支持配置保存和批量处理

**插件特点**：
- ✅ 完全独立运行，无需Node.js环境
- ✅ 无需Web服务器，直接在浏览器中使用
- ✅ 支持Chrome、Edge等基于Chromium的浏览器
- ✅ 使用Manifest V3，符合最新Chrome扩展规范

## 系统要求

### 浏览器要求
- **Chrome浏览器** 版本 88 或更高
- **Microsoft Edge浏览器** 版本 88 或更高
- **其他基于Chromium的浏览器**（如Opera、Brave等）

### 操作系统要求
- ✅ Windows 7 或更高版本
- ✅ macOS 10.12 或更高版本
- ✅ Linux（Ubuntu 16.04 或更高版本）

### 其他要求
- 无需安装Node.js
- 无需安装任何服务器软件
- 只需要一个支持Chrome扩展的浏览器

## 安装方式

### 方式一：从源码加载（开发模式）

**适用场景**：
- 您已经下载了完整的项目源码
- 想要进行开发或调试
- 需要频繁更新插件代码

**步骤**：

1. **定位插件目录**
   ```bash
   # 进入项目根目录
   cd /path/to/xiaohongshu
   
   # 确认extension目录存在
   ls extension/
   ```

2. **打开Chrome扩展管理页面**
   - 在Chrome浏览器地址栏输入：`chrome://extensions/`
   - 或者：菜单 → 更多工具 → 扩展程序

3. **启用开发者模式**
   - 在扩展管理页面右上角，找到"开发者模式"开关
   - 将开关切换到**开启**状态

4. **加载扩展**
   - 点击页面左上角的"**加载已解压的扩展程序**"按钮
   - 在弹出的文件选择对话框中，选择项目的 `extension` 目录
   - 点击"选择文件夹"或"选择"按钮

5. **确认安装**
   - 插件应该会立即出现在扩展列表中
   - 浏览器工具栏会显示插件图标

---

### 方式二：从打包文件加载（生产模式）

**适用场景**：
- 您已经获得了打包好的插件文件（.zip格式）
- 需要在多台电脑上安装
- 不需要修改插件代码

**步骤**：

1. **解压插件文件**

   - 选择"解压到当前文件夹"或"全部提取"

   **macOS系统**：
   ```bash
   # 双击zip文件自动解压
   # 或使用命令行
   unzip xiaohongshu-extension.zip
   ```

   **Linux系统**：
   ```bash
   unzip xiaohongshu-extension.zip
   ```

2. **打开Chrome扩展管理页面**
   - 在Chrome浏览器地址栏输入：`chrome://extensions/`
   - 或者：菜单 → 更多工具 → 扩展程序

3. **启用开发者模式**
   - 在扩展管理页面右上角，找到"开发者模式"开关
   - 将开关切换到**开启**状态

4. **加载扩展**
   - 点击页面左上角的"**加载已解压的扩展程序**"按钮
   - 在弹出的文件选择对话框中，选择解压后的 `extension` 目录
   - 点击"选择文件夹"或"选择"按钮

5. **确认安装**
   - 插件应该会立即出现在扩展列表中
   - 浏览器工具栏会显示插件图标

## 详细安装步骤

### 步骤1：准备插件文件

#### 如果您有项目源码：
```bash
# 进入项目目录
cd /path/to/xiaohongshu

# 确认extension目录存在
ls -la extension/
```

您应该看到以下文件结构：
```
extension/
├── manifest.json          # 扩展配置文件
├── background/            # 后台脚本
├── content/              # 内容脚本
├── popup/                # 弹出窗口
├── options/              # 选项页面
├── lib/                  # 库文件
├── assets/               # 资源文件
└── help/                 # 帮助页面
```

#### 如果您有打包文件：
解压 `xiaohongshu-extension.zip` 文件，确保得到 `extension` 文件夹。

---

### 步骤2：打开Chrome扩展管理页面

**方法一：通过地址栏**
1. 打开Chrome浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 按回车键

**方法二：通过菜单**
1. 点击Chrome右上角的三个点（菜单图标）
2. 选择"更多工具"
3. 选择"扩展程序"

**方法三：通过快捷键**
- Windows/Linux: `Ctrl + Shift + E`
- macOS: `Cmd + Shift + E`

---

### 步骤3：启用开发者模式

1. 在扩展管理页面右上角，找到"**开发者模式**"开关
2. 点击开关，将其切换到**开启**状态
3. 开关变为蓝色表示已启用

**注意**：启用开发者模式后，页面会显示额外的按钮和选项。

---

### 步骤4：加载扩展程序

1. 点击页面左上角的"**加载已解压的扩展程序**"按钮
   - 这个按钮只有在启用开发者模式后才会显示

2. 在弹出的文件选择对话框中：
   - **Windows**: 浏览到 `extension` 文件夹，选择该文件夹，点击"选择文件夹"
   - **macOS**: 浏览到 `extension` 文件夹，选择该文件夹，点击"打开"
   - **Linux**: 浏览到 `extension` 文件夹，选择该文件夹，点击"打开"

3. **重要提示**：
   - 必须选择 `extension` 文件夹本身，而不是其父目录
   - 确保选择的文件夹中包含 `manifest.json` 文件

---

### 步骤5：确认安装成功

安装成功后，您应该看到：

1. **扩展列表中出现插件**
   - 插件名称：**小红书餐馆图片下载工具**
   - 版本号：1.0.0
   - 状态：已启用

2. **浏览器工具栏显示图标**
   - 在Chrome工具栏（地址栏右侧）可以看到插件图标
   - 如果看不到，点击工具栏右侧的扩展图标（拼图图标），找到插件并点击图钉图标固定到工具栏

3. **无错误提示**
   - 如果安装成功，不会显示任何错误信息
   - 如果看到错误提示，请参考[常见问题](#常见问题)部分

## 常见问题

### ❓ 问题1：找不到"加载已解压的扩展程序"按钮

**原因**：未启用开发者模式

**解决方法**：
1. 在扩展管理页面右上角找到"开发者模式"开关
2. 将开关切换到开启状态
3. 按钮会立即显示出来

---

### ❓ 问题2：提示"无法加载扩展程序。清单文件缺失或不可读"

**原因**：选择的目录不正确或缺少 `manifest.json` 文件

**解决方法**：
1. 确认选择的是 `extension` 文件夹本身
2. 确认 `extension` 文件夹中包含 `manifest.json` 文件
3. 检查文件路径是否正确
4. 重新选择正确的文件夹

---

### ❓ 问题3：提示"扩展程序无效：清单文件无效"

**原因**：`manifest.json` 文件格式错误或版本不兼容

**解决方法**：
1. 检查Chrome浏览器版本是否过旧（需要Chrome 88+）
2. 更新Chrome浏览器到最新版本
3. 确认 `manifest.json` 文件完整且格式正确
4. 如果是从源码加载，确保所有文件都已正确下载

---

### ❓ 问题4：插件图标不显示

**原因**：插件已安装但未固定到工具栏

**解决方法**：
1. 点击Chrome工具栏右侧的扩展图标（拼图图标）
2. 在弹出菜单中找到"小红书餐馆图片下载工具"
3. 点击插件右侧的图钉图标，固定到工具栏
4. 或者右键点击插件图标，选择"固定"

---

### ❓ 问题5：插件显示错误或无法使用

**原因**：可能是权限问题或文件缺失

**解决方法**：
1. 打开 `chrome://extensions/`
2. 找到插件，点击"详细信息"
3. 检查"权限"部分，确认所有权限都已授予
4. 检查"错误"部分，查看具体错误信息
5. 尝试重新加载插件（点击刷新图标）
6. 如果问题持续，尝试卸载后重新安装

---

### ❓ 问题6：在Edge浏览器中无法安装

**解决方法**：
1. Edge浏览器也支持Chrome扩展
2. 打开 `edge://extensions/`
3. 启用"开发人员模式"
4. 点击"加载解压缩的扩展"
5. 选择 `extension` 文件夹

---

### ❓ 问题7：插件安装后无法访问小红书网站

**原因**：可能是网络问题或权限问题

**解决方法**：
1. 检查网络连接是否正常
2. 确认插件已授予访问小红书网站的权限
3. 在扩展详情中检查"网站访问权限"
4. 尝试重新加载插件

│   └── content.css       # 内容样式

├── assets/               # 资源文件
│   ├── icons/           # 图标文件

### 权限说明

插件需要以下权限：

- **downloads**: 下载图片文件
- **storage**: 保存配置和缓存数据
- **cookies**: 访问小红书网站的Cookie（用于登录状态）
- **tabs**: 访问和管理浏览器标签页
- **activeTab**: 访问当前活动标签页
- **notifications**: 显示通知消息
- **host_permissions**: 访问小红书网站和AI服务API

这些权限都是插件正常运行所必需的，不会用于其他目的。
